# Инструкция по проекту Agent-Ayuemin

Репозиторий: https://github.com/Ayuemin/Agent-Ayuemin
Roadmap: https://github.com/Ayuemin/Agent-Ayuemin/blob/main/ROADMAP.md
Сборки: https://github.com/Ayuemin/Agent-Ayuemin/actions/workflows/debug-apk.yml
APK: https://github.com/Ayuemin/Agent-Ayuemin/releases

1. Перед изменениями прочитай ROADMAP.md и фактический код.
2. Обсуди список изменений и затрагиваемых классов; новые функции — отдельные классы/модули, без монолитов и регрессий.
3. После работы проверь сборку и существующие функции, честно зафиксируй, что не удалось проверить.
4. Обновляй ROADMAP.md после каждого этапа и при появлении новых согласованных задач.
5. Главный приоритет: доступный API-чат с экономией токенов, гибридным RAG, саммаризацией и сохранением полной истории.
